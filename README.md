# 전기설비 허브 (Electrical Hub)

전기공사 현장과 설계를 위한 무료 계산기 사이트입니다. GitHub Pages 정적 사이트로, 모든 계산은 브라우저 안에서 처리됩니다.

- **라이브 주소:** https://electricalcalc.github.io/
- **기준:** KS C IEC 60364, 전기설비기술기준(KEC), 380V 3상 / 220V 단상, 60Hz
- **언어:** 한국어

## 계산기 5종

1. **전선 굵기·허용전류** — 부하전류와 설치 방법, 주위 온도를 입력하면 CV 케이블의 적정 굵기를 찾습니다.
2. **차단기 용량 선정** — MCCB와 누전차단기(ELB) 정격, 감도전류를 선정합니다.
3. **전압강하** — KEC 기준(분기 3%, 합계 5%) 판정과 최소 전선 굵기를 계산합니다.
4. **3상 전류·전력** — 정격전류, 피상전력, 무효전력, 기동전류를 계산합니다.
5. **부하용량·수요율** — 용도별 설비용량과 수요율로 최대수요전력과 수전 용량을 계산합니다.

## 실무 가이드 6편

- 분전반 결선 실무
- 접지공사와 접지저항
- 누전차단기 선정과 오동작 대책
- 케이블 포설과 전선관 공사
- 절연저항 측정 실무
- 전기설비 점검과 안전관리

모든 가이드는 `guides/` 폴더의 독립 페이지로 열립니다.

## 면책

모든 계산 결과는 참고용 추정치입니다. 실제 시공에서는 기기 명판 데이터, 최신 전기설비기술기준(KEC), 한국전력 수전설비 기준을 확인하고 자격을 갖춘 전기기술자의 판단에 따라야 합니다.
